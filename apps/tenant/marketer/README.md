# AI-маркетолог (VK Autopilot) — PoV

Генерирует контент для стены VK-сообщества из живых данных лояльности.
Первый этап трека «2а. AI-маркетолог» (см. артефакт «Штаб LoyalUP»).

## Что умеет (PoV)

- **Knowledge Core** (`knowledge.py`) — снимок фактов тенанта: бренд, точки,
  статистика недели (новые гости / визиты / выдано и забрано подарков),
  цитаты позитивных отзывов (анонимно), RF-сводка, каталог наград.
- **Дайджест «Что нового?»** (`generator.py`) — еженедельный пост через Claude
  (модель `MARKETER_AI_MODEL`, дефолт `claude-sonnet-5`). Железное правило
  промпта: только факты из Knowledge Core + заметок владельца, ничего не выдумывать.
- **Публикация** (`publisher.py`) — `wall.post` от имени сообщества.

## Безопасность каналов

- Токен для стены — **ОТДЕЛЬНОЕ поле** `MarketerSettings.vk_wall_token`.
  НИКОГДА не использовать senler-токен: спам-флаг за постинг уронит отзывы
  и рассылки.
- `wall.post` требует **пользовательский токен админа сообщества**
  (scope `wall,photos,offline`) — community-токен этот метод не пускает.

## Режимы

Всё выключено по умолчанию (`is_enabled=False`). Даже включённый маркетолог
по умолчанию готовит **только черновики** (`autopost_enabled=False`) —
владелец смотрит пост в админке («Посты маркетолога») и публикует кнопкой.

## Расписание

Beat-тик `marketer-digest-hourly` каждый час в :10 (МСК). Пер-тенантная
генерация — когда совпали `digest_weekday` + `digest_hour` и сегодня ещё
не готовили (`last_digest_at`). Ручной запуск: админка → Настройки
AI-маркетолога → действие «📝 Сгенерировать дайджест сейчас».

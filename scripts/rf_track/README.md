# RF-трек: E2E и скрипты пилота (август 2026)

Запуск на проде: `cat <скрипт> | ssh checkup-prod 'docker exec -i web python manage.py shell'`

- `e2e_orchestrator.py` — 10 проверок RF-оркестратора (фаза 3), rollback.
- `e2e_phase5.py` — 26 проверок RFM-кампаний/выдачи/сгорания/активации (фаза 5), rollback.
- `e2e_phase6.py` — 7 проверок атрибуции возврата и контрольной группы (фаза 6), rollback.
- `create_rf_rules.py` — 5 M0-правил пилота на levone (идемпотентно, РЕАЛЬНОЕ создание).
- `create_gift_rules.py` — подарочные G1-правила + напоминание (идемпотентно, РЕАЛЬНОЕ).

E2E-скрипты работают в transaction.atomic + set_rollback(True) — прод не трогают,
ничего не отправляют. Скрипты правил — боевые: правила создаются и включаются.
